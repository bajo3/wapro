---
name: catalog-truth-check
description: Verificar que cualquier respuesta o lógica que toque stock, precio, moneda, versión o disponibilidad tenga evidencia suficiente.
---

## Checklist
- fuente de datos confirmada
- moneda confirmada
- unidad existe o no existe
- disponibilidad confirmada o no confirmada
- lenguaje seguro si faltan datos

## Regla
Si no hay evidencia suficiente, no afirmar.

# Casos de regresión

## Catálogo
- Panel stock muestra autos cuando bot ve stock.
- `/admin/catalog-debug` responde.
- Cotizaciones lista más de 15 autos.

## Bot comercial
- "Busco Amarok 2021 automática hasta 35 millones" debe devolver matches si existen.
- "Tenés Corolla automático?" no debe responder genérico si hay catálogo.
- "Mostrame pickups para trabajar" debe usar carrocería e intención.

# Memory Policy — WaPro Elite

## Principio
La memoria debe servir para decidir mejor, no para acumular texto.

## Guardar siempre
- hechos estables del negocio
- contratos de API importantes
- bugs reincidentes
- reglas comerciales duras
- preferencias persistentes del proyecto
- mejoras confirmadas y su fecha

## No guardar
- razonamientos largos descartados
- hipótesis no validadas
- logs crudos extensos
- conversaciones repetitivas sin valor futuro

## Formato ideal de memoria
- título corto
- fecha
- qué cambió
- por qué importa
- cómo aplicarlo después

## Política de compactación
Si la memoria supera lo útil:
1. conservar decisiones
2. conservar reglas
3. conservar anomalías recurrentes
4. borrar ruido narrativo

# Agent Memory

La memoria por agente existe para guardar contexto estable del proyecto, no para acumular ruido.

## Reglas
- guardar solo información útil para próximas tareas
- preferir índices cortos y documentos puntuales
- evitar duplicar lo que ya está en `docs/`
- si una memoria queda obsoleta, actualizarla o borrarla

---
name: Estilo de análisis de deploy
description: Formato y profundidad de análisis esperado al revisar cambios de deploy en WaPro
type: feedback
---

El análisis de cambios debe incluir: capa de falla, causa raíz, env/config afectados, fix aplicado o recomendado, validación local + Railway, riesgos pendientes.

**Why:** El usuario solicitó explícitamente ese formato de entrega para tener visibilidad operativa completa.
**How to apply:** Siempre estructurar las respuestas de auditoría de deploy con esas secciones. No cerrar un caso solo porque compila.
